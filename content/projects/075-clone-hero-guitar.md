A Rock Band Stratocaster rebuilt as an Arduino USB controller for Clone Hero, with light-up fret buttons.

The original buttons wouldn't let the LEDs shine through, so I learned enough CAD to design and 3D-print replacements. An Arduino Leonardo handles the USB controller side, and individually addressable LEDs light the frets. This build involved a lot of button revisions, soldering, and hot glue.
