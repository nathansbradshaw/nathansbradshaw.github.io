Build a four-page baptism program that prints on a single sheet, double-sided and folded in half.

Start with a template, then move text, hymns, images, and other elements around while the preview updates. Download an editable save to come back to later; printing puts the pages in the order needed for the folded booklet. The editor runs in the browser, written in Rust and compiled to WebAssembly.
